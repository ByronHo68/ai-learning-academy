Stock research projection · week 2

股票研究規劃 · 第 2 週

n8n fetches the news. It does not write the report.

n8n 負責抓新聞，不負責寫報告。

n8n is a visual workflow runner. In this project it is the clerk between your research app and the news source: one accepted question comes in, company news goes out, and a receipt proves what was saved.

n8n 是一個視覺化流程執行器。在這個專案裡，它是研究 app 與新聞來源之間的辦事員：收下一條已接納的問題，交出公司新聞，並用一張收據證明保存了什麼。

What n8n is, in this project

在這個專案裡，n8n 是什麼

A workflow is a row of boxes. Each box does one small job, then passes its result to the next box. Something has to start the row: a button, a clock, or another program calling a URL. n8n is the program that stores those boxes and runs them.

一條 workflow 是一排方塊。每塊只做一件小事，再把結果交給下一塊。必須有東西啟動這排方塊：一個按鈕、一個時鐘，或其他程式呼叫一個網址。n8n 就是保存並執行這些方塊的程式。

Your financial projection is an interview research app for three US companies: MSFT, AAPL, and NVDA. The language model writes a cited note only after news has been fetched, saved, and pinned. n8n owns that fetch. The model is not allowed to skip it, and the model is not allowed to retry the news source on its own.

你的財務規劃是一個面試用研究 app，只處理三家美國公司：MSFT、AAPL、NVDA。語言模型要在新聞已被抓取、保存並固定之後，才寫有引用的報告。抓取由 n8n 負責。模型不能跳過這一步，也不能自己向新聞來源重試。

Piece部分 Its job它的工作
LangGraph host Checks the question, then calls refresh_company_news once. 檢查問題，然後只呼叫 refresh_company_news 一次。
n8n Validates the call, fetches news, retries transient failures, saves rows, returns a receipt. 驗證呼叫、抓新聞、對暫時失敗重試、保存紀錄、交回收據。
YFinance adapter Private HTTP bridge on port 8002. n8n calls POST /news or POST /quote. 私人 HTTP 橋接，埠 8002。n8n 呼叫 POST /news 或 POST /quote。
PostgreSQL The evidence database. n8n may insert news. It may not read or write reports. 證據資料庫。n8n 可以寫入新聞，不能讀寫報告。
The model Writes the cited note from the pinned snapshot. It starts only after n8n is finished. 根據已固定的快照寫有引用的報告。它在 n8n 完成之後才開始。

Inside n8n

n8n 內部

    Two workflows, not one

    兩條流程，不是一條

    A. Every accepted question

    A. 每條已接納的問題

    Name the tool refresh_company_news. The app calls it through an MCP Server Trigger. A daily clock must not replace this call. Two different questions need two receipts.

    工具名稱是 refresh_company_news。App 經 MCP Server Trigger 呼叫它。每日時鐘不能取代這次呼叫。兩條不同問題要有兩張收據。

    1. Arguments: company, query, as_of, run_id, deadline.
    2. 參數：company、query、as_of、run_id、deadline。
    3. If this run_id already has a receipt, return that receipt.
    4. 若這個 run_id 已有收據，交回那張收據。
    5. Otherwise fetch, save, and return version ids, fetched_at, and provider status.
    6. 否則抓取、保存，並交回版本 id、fetched_at 與供應商狀態。

    B. Once a day, even if nobody asks

    B. 每天一次，即使沒有人發問

    A Schedule Trigger fetches macroeconomic and geopolitical news into shared PostgreSQL rows. Pick the clock and the timezone when you publish the workflow. This batch is context. It is not the company news for the question.

    Schedule Trigger 把宏觀與地緣政治新聞抓進共用的 PostgreSQL 紀錄。發布流程時選定時間與時區。這批資料是背景，不是該題的公司新聞。

    1. Same retry limits, with this job’s own deadline.
    2. 同樣的重試上限，但使用這份工作自己的時限。
    3. If retries run out, keep yesterday’s completed batch and record the failure.
    4. 若重試用完，保留昨天已完成的批次，並記下失敗。
    5. The next question pins that batch beside the fresh company news.
    6. 下一條問題會把該批次與新的公司新聞一起固定。

    How to start n8n

    怎樣開始用 n8n

    Use Docker. From n8n 3.0, new installs are distributed with Docker. This academy’s Node.js 18.18 runs the website only. It is too old for n8n’s npm installer, which wants Node.js 20.19 through 24.

    請用 Docker。 由 n8n 3.0 起，新安裝透過 Docker 發行。這個學院的 Node.js 18.18 只負責網站，版本低於 n8n 的 npm 安裝要求（Node.js 20.19 至 24）。

    1

    Open an empty n8n

    先打開一個空白的 n8n

    Install Docker and leave it running. In a folder that is not this git repository, run the official one-line setup. It creates a n8n directory, downloads the editor, and starts it.

    安裝 Docker 並保持執行。在這個 git 倉庫以外的資料夾，執行官方一行安裝。它會建立 n8n 目錄、下載編輯器並啟動。

    mkdir -p "$HOME/n8n-local" && cd "$HOME/n8n-local"
curl -fsSL https://get.n8n.io | sh

    Open http://localhost:5678 and create the owner account. That account stays on your machine. Official notes: n8n one-line setup.

    打開 http://localhost:5678 並建立擁有者帳戶。帳戶留在你的電腦。官方說明：n8n 一行安裝。

    2

    Learn the editor with a throwaway workflow

    用一條可丟棄的流程熟悉編輯器

    Create a workflow. Add a Manual Trigger. Add an Edit Fields node and set symbol to MSFT. Execute it, then open the Executions list and click that run. You have now seen a workflow start, pass data, and keep a history. This practice flow is not part of the finance app. Leave it or delete it.

    建立一條流程。加入 Manual Trigger。加入 Edit Fields，把 symbol 設為 MSFT。執行它，然後打開 Executions 並點進該次執行。你已經看過流程啟動、傳遞資料和保留歷史。這條練習流程不屬於財務 app，可留下或刪除。

    3

    Build the company-news tool

    建立公司新聞工具

    The shape from the projection, before any live Yahoo call:

    規劃裡的形狀，在呼叫真實 Yahoo 之前：

    1. Create the sub-workflow that validates the company, checks run_id, calls the adapter, retries, and returns a receipt.
    2. 建立子流程：驗證公司、檢查 run_id、呼叫 adapter、重試，並交回收據。
    3. Add an MCP Server Trigger. Connect a Custom n8n Workflow Tool named refresh_company_news. The trigger connects to tool nodes, not to ordinary action nodes.
    4. 加入 MCP Server Trigger，接上名為 refresh_company_news 的 Custom n8n Workflow Tool。Trigger 連接的是 tool 節點，不是一般動作節點。
    5. Choose Header auth or Bearer auth. Copy the test URL. Publish the workflow before using the production URL. Use Streamable HTTP. This trigger does not speak stdio.
    6. 選擇 Header auth 或 Bearer auth。複製測試網址。發布之後才使用正式網址。使用 Streamable HTTP。這個 trigger 不支援 stdio。

    This MCP Server Trigger is the door for the research app. It is a different feature from Settings → Instance-level MCP, which lets a chat client browse your n8n instance. The projection uses the trigger.

    這個 MCP Server Trigger 是研究 app 的門口。它和 Settings → Instance-level MCP 不同；後者是讓聊天客戶端瀏覽整個 n8n。規劃使用的是 trigger。

    4

    Point the HTTP node at the private adapter

    把 HTTP 節點指向私人 adapter

    The adapter lives on the finance branch codex/rich-animated-ts, not on this academy’s main branch. When that adapter is running, n8n calls it like this:

    Adapter 在財務分支 codex/rich-animated-ts，不在這個學院的 main。當 adapter 在跑，n8n 這樣呼叫它：

    • Credential: Header Auth, header name X-YFinance-Token, same secret as YFINANCE_BRIDGE_TOKEN.
    • 憑證：Header Auth，標頭名稱 X-YFinance-Token，密鑰與 YFINANCE_BRIDGE_TOKEN 相同。
    • News: POST http://127.0.0.1:8002/news with {"symbol":"MSFT","max_items":5}. Map symbol from the validated company.
    • 新聞：POST http://127.0.0.1:8002/news，內容 {"symbol":"MSFT","max_items":5}。symbol 取自已驗證的公司。
    • Price, only when the report needs it: POST /quote with {"symbol":"MSFT"}, as a separate tool.
    • 只有報告需要價格時：POST /quote，內容 {"symbol":"MSFT"}，作為另一個工具。
    • If n8n itself is in Docker, 127.0.0.1 means the n8n container. Use the adapter’s private service name instead, for example http://yfinance-bridge:8002.
    • 若 n8n 自己在 Docker 裡，127.0.0.1 指的是 n8n 容器。改用 adapter 的私人服務名稱，例如 http://yfinance-bridge:8002。
    5

    Week 2 is done when two questions leave two receipts

    第 2 週的完成線：兩題留下兩張收據

    The projection’s acceptance line is small on purpose. Run two different supported prompts. Each one gets its own refresh receipt. If the host times out, it looks up that run_id before sending the call again. Replaying a finished run returns the old receipt and does not fetch a second time.

    規劃的驗收刻意很小。跑兩條不同、且在支援範圍內的問題。每一題有自己的刷新收據。若 host 超時，它先用該 run_id 查找，再決定要不要重送。重播已完成的任務會交回舊收據，不會再抓一次。

    The retry rules already written down

    已經寫好的重試規則

    n8n may retry

    n8n 可以重試

    • A dropped connection, selected HTTP 500s, and 429, 503, or 504.
    • 連線中斷、部分 HTTP 500，以及 429、503、504。
    • Only while attempts are under 3 and the remaining time can hold another 10-second call.
    • 只有在次數少於 3，而且剩餘時間夠再打一次 10 秒呼叫時。
    • Wait 1 second, then 2 seconds, plus a little jitter. Honor a Retry-After header when it fits the deadline.
    • 先等 1 秒，再等 2 秒，加上少量 jitter。若 Retry-After 仍在時限內，就遵守它。

    n8n must stop

    n8n 必須停止

    • HTTP 401 or 422, an unknown company, or a body that does not match the schema.
    • HTTP 401 或 422、不認識的公司，或不符合 schema 的內容。
    • Turn off the HTTP node’s own automatic retry. The explicit Wait branch is the only retry.
    • 關掉 HTTP 節點自帶的自動重試。只有明確的 Wait 分支才是重試。
    • The app does not blindly call the tool again after a timeout. It reconciles the receipt first.
    • App 在超時後不會盲目再呼叫工具。它先核對收據。

    n8n’s own installer database is SQLite. It remembers your workflows, credentials, and execution list. The news articles go to PostgreSQL. Those are two databases. Giving n8n a login that can write reports or LangGraph checkpoints would break the projection’s rule: n8n gets an ingestion-only database role.

    n8n 安裝程式自帶的資料庫是 SQLite。它記住你的流程、憑證和執行清單。新聞文章要進 PostgreSQL。這是兩個資料庫。若給 n8n 一個能寫報告或 LangGraph checkpoint 的帳戶，就違反規劃：n8n 只有匯入用的資料庫角色。

    同一份規劃的第 1 週凍結證據合約和評估集。第 3 至 8 週才加上研究 graph、混合搜尋、追蹤、安全和示範。學這一段 n8n 不需要 Langfuse、pgvector 或公開網址。
